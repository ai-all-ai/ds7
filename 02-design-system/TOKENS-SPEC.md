# 02-Design-System · Tokens Specification

> Дизайн-токены определяют визуальную ДНК проекта. Все значения объявляются через CSS Custom Properties в файле `theme.css`.

---

## 1. Палитра цветов (Semantic Color System)

```css
:root {
  /* Базовые цвета поверхностей */
  --color-paper: #f7f5ef;        /* Теплый фон страниц */
  --color-white: #ffffff;        /* Белые плашки и карточки */
  --color-ink: #1f1b16;          /* Основной контрастный текст */
  --color-ink-500: #6b6459;      /* Второстепенный поясняющий текст */
  --color-ink-100: rgba(31, 27, 22, 0.08); /* Границы и разделители */
  --color-ink-950: #12100d;      /* Глубокий темный фон для инверсий */

  /* Фирменный солнечный акцент */
  --color-sun: #ffd84d;          /* Теплый солнечный акцент */
  --color-sun-hover: #ffcf2e;    /* Состояние ховера */

  /* Семантические цвета */
  --color-success: #2e7d32;      /* Подтверждение, экономия */
  --color-warning: #ed6c02;      /* Предупреждение */
  --color-error: #d32f2f;        /* Ошибки */
}
```

> **Правило контрастности:** Желтый цвет `--color-sun` запрещено использовать для текста. Он применяется только как фоновая заливка кнопок (`.btn.-sun`), бейджей или подложка-маркер (`box-shadow: inset 0 -0.3em 0 var(--color-sun)`).

## 2. Ритм вертикальных и горизонтальных отступов (Spacing Scale)

```css
:root {
  --space-1: 0.25rem;  /* 4px */
  --space-2: 0.5rem;   /* 8px */
  --space-3: 0.75rem;  /* 12px */
  --space-4: 1rem;     /* 16px */
  --space-6: 1.5rem;   /* 24px */
  --space-8: 2rem;     /* 32px */
  --space-12: 3rem;    /* 48px */
  --space-16: 4rem;    /* 64px */

  /* Семантический интервал секций (Responsive) */
  --space-single: clamp(1.2rem, 3vw, 2.2rem);  /* Внутренний отступ блоков */
  --space-double: clamp(2.4rem, 6vw, 4.5rem);  /* Стандартный интервал секций */
  --space-triple: clamp(3.6rem, 9vw, 6.5rem);  /* Крупные разделы на десктопе */

  /* Базовая сетка страницы */
  --content-width: 78rem;  /* 1248px */
  --page-gutter: clamp(1rem, 3.5vw, 2rem);
}
```

## 3. Тени и глубина поверхностей (Elevation)

Вместо случайных значений `box-shadow` используются строгие семантические токены:

```css
:root {
  /* Обычные карточки и панели в состоянии покоя */
  --shadow-lift: 0 4px 16px -2px rgba(31, 27, 22, 0.06);

  /* Приподнятые карточки при ховере или раскрытые элементы */
  --shadow-hover: 0 12px 32px -4px rgba(31, 27, 22, 0.12);

  /* Всплывающие модальные окна */
  --shadow-modal: 0 24px 64px -8px rgba(18, 16, 13, 0.24);
}
```

---

## 4. Скругления (Border Radius)

```css
:root {
  --radius-sm: 0.375rem; /* 6px — бейджи, кнопки-чипы */
  --radius-md: 0.75rem;  /* 12px — карточки, инпуты */
  --radius-lg: 1.25rem;  /* 20px — большие секционные плашки */
  --radius-full: 9999px; /* Таблетки, круглые кнопки */
}
```
